### Geçit (yeni)
- Türkiye'de engellenen site ve uygulamaları VPN olmadan açar; sağ üstteki anahtarla tek tıkla açılıp kapanır
- Önce şifreli DNS'i (Cloudflare, DNS over HTTPS) açar; yetmezse servis sağlayıcıya göre ayarlanmış bir paket motoru (zapret) devreye girer, sesli sohbet dahil
- Bilgisayar yeniden başlasa da açık kalır; Windows açılışında saatin yanında başlar
- Kapatınca önceki ağ ayarlarınız aynen geri gelir
- Saatin yanında kendi simgesi: gri kapalı, turuncu geçiş sırasında, yeşil açık; sağ tıkla açılıp kapanır, istenirse gizlenebilir
- Komut satırı: `Benchwise-cli.exe --hideme` (açar), `--hideme off`, `--hideme status`

### Düzeltmeler
- Canlı takip açıkken başka bir klasöre indirilen yeni sürüm artık eskisini açmıyor; görev yeni exe'ye taşınıyor

### Passage (new)
- Opens sites and apps blocked in Türkiye without a VPN; one switch at the top right
- First turns on encrypted DNS (Cloudflare, DNS over HTTPS); if that is not enough, a packet engine (zapret) tuned for providers in Türkiye takes over, voice chat included
- Stays on after a restart; starts next to the clock when Windows starts
- Switching it off puts your previous network settings back exactly
- Its own icon next to the clock: grey off, orange while switching, green on; right-click to switch, can be hidden
- Command line: `Benchwise-cli.exe --hideme` (on), `--hideme off`, `--hideme status`

### Fixes
- With live monitoring on, a newer version downloaded to another folder no longer opens the old one; the task moves to the new exe
