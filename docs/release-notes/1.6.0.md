### İmaj ve Klonlama
- Yeni yedekleme ekranı: USB bellek, hafıza kartı veya diskin (ya da tek bir bölümün) imajı seçtiğiniz klasöre alınır
- Gereken alan ve hedefteki boş alan anında gösterilir; yer yetmiyorsa veya imaj kopyalanan diskin üzerine kaydedilmek isteniyorsa başlatılamaz
- Yedekler .vhd dosyasıdır: Windows bunları gerçek disk olarak bağlayabilir, kurtarma araçları ham imaj olarak açabilir
- Yeni geri yükleme ekranı: imajı (.vhd, .vhdx, .iso) seçtiğiniz harfe bağlayın, Bu Bilgisayar'da o sürücü olarak görünür
- Yalnızca boş harfler seçilebilir; birden fazla imaj aynı anda farklı harflere bağlanabilir; Çıkar ile kaldırılır
- Salt okunur bağlama varsayılan olarak açık (yedeği korur); liste saklanır, yeniden başlatmadan sonra tek tıkla tekrar bağlanır

### Kopya Dosya Bulucu
- Uzun yol yerine yalnızca dosya adı, tarih ve klasör adı gösterilir
- Her dosyanın yanında konuma git ve sil (Geri Dönüşüm Kutusu) simgeleri; bir dosyanın son kopyası silinmez
- Klasör seçme penceresi artık programın klasöründe değil, kullanıcı klasöründe açılır

### Yönetici
- Üst çubukta, Geçit'in yanında "Yönetici" anahtarı: açıkken Benchwise her zaman UAC sormadan yönetici olarak açılır, bilgisayar yeniden başlasa da
- Kalkan işaretli bir araca tıklayınca araya soru kutusu girmeden doğrudan Windows izni (UAC) istenir

### Image & Clone
- New backup screen: a USB stick, memory card or disk (or one partition) is imaged into the folder you choose
- The space needed and the free space at the destination are shown at once; it cannot start without enough room or onto the disk being copied
- Backups are .vhd files: Windows can attach them as real disks, recovery tools open them as raw images
- New restore screen: mount an image (.vhd, .vhdx, .iso) on the letter you pick, and it shows in This PC as that drive
- Only free letters can be picked; several images can be mounted on different letters at once; Eject removes one
- Read-only mounting is on by default (protects the backup); the list is kept and mounts again with one click after a restart

### Duplicate Finder
- Only the file name, date and folder name instead of the long path
- Go-to-location and delete (Recycle Bin) icons next to every file; the last copy of a file is never deleted
- The folder picker opens in your user folder, not the program's folder

### Administrator
- "Administrator" switch in the top bar, next to Passage: on, Benchwise always opens as administrator without a UAC prompt, also after a restart
- Clicking a tool with a shield goes straight to the Windows prompt (UAC), without a question box first
