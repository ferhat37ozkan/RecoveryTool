### Disk sıcaklığı saatin yanında
- Disk Sağlığı'nda "Saatin yanında" seçilen disklerin sıcaklığı bildirim alanında kendi simgesiyle
- Varsayılan 15 saniyede bir güncelleme (5 / 15 / 30 / 60 sn seçilebilir); sağlık yüzdesi ipucunda
- Canlı izleme modu: tek onayla her zaman yönetici, istenirse Windows ile arka planda başlar
- Seviye başına simge ve rakam renkleri seçilebilir
- AMD RAID dizisi seçilince içindeki bütün diskler seçiliyor

### Uygulama içi güncelleme
- "İndir ve kur" yeni sürümü ilerleme çubuğuyla indirir, SHA-256 ile doğrular ve yeniden başlatır

### Yeni araçlar
- Ekran ve Giriş: ölü piksel, klavye, fare, hoparlör/mikrofon ve kamera testleri
- Sistem: sistem bilgisi, bellek testi, çökme (mavi ekran) analizi, işlemci stres testi
- Güç: pil sağlığı, uyanma ve uyku sorunları
- Ağ: bağlantı tanılama, hız testi (Cloudflare), Wi-Fi analizi, ağ sıfırlama
- Windows Onarımı: SFC/DISM, Windows Update onarımı, sürücü sorunları, başlangıç programları ve hizmetler
- Temizlik: gereksiz dosyalar (siz seçersiniz), kopya dosya bulucu, alan analizi
- Disk: yüzey taraması, hız testi, disk onarım kontrolleri, imaj alma, bölümler ve tablo yedeği, güvenli silme önizlemesi
- Diske doğrudan yazan işlemler (onarım, klonlama, bölüm değişiklikleri, silme) bu sürümde kilitli

### Düzeltmeler
- Açılışta titreme yok; aynı anda tek Benchwise çalışıyor

### Disk temperatures by the clock
- Disks ticked "By the clock" in Disk Health show their temperature in the notification area
- Refreshed every 15 seconds by default (5 / 15 / 30 / 60 s); health percentage in the tooltip
- Live monitoring mode: always administrator after one consent, optionally starts with Windows in the background
- Icon and digit colours per level can be chosen
- Ticking an AMD RAID array ticks every disk inside it

### In-app update
- "Download and install" downloads the new version with a progress bar, checks its SHA-256 and restarts

### New tools
- Display & input: dead pixel, keyboard, mouse, speaker/microphone and camera tests
- System: system information, memory test, crash (blue screen) analysis, CPU stress test
- Power: battery health, wake and sleep problems
- Network: connection diagnosis, speed test (Cloudflare), Wi-Fi analysis, network reset
- Windows repair: SFC/DISM, Windows Update repair, driver problems, startup programs and services
- Cleanup: junk files (you choose), duplicate finder, space analyzer
- Disk: surface scan, speed test, disk repair checks, imaging, partitions and table backup, secure erase preview
- Anything that writes to a disk directly (repair, cloning, partition changes, erasing) is locked in this version

### Fixes
- No flicker at start-up; only one Benchwise runs at a time
